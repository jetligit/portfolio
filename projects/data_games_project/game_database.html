Video Game Database Project

⬇ Download Application Domain

This was a project done in a team of four. A PostgreSQL-backed command line interface application using a relational database to store information about video games and users. Users can create an account, login, play games, search for games, manage collections, rate games, get recommendations, and view the top 20 most popular games via SQL prepared statements.

Skills Java, SQL, Github, Excel
Tools Datagrip and IntelliJ

ER Diagram

We designed an Entity-Relationship (ER) Diagram to describe how each entity in the project relates to one another. We then reduced this into tables and laid out constraints for our data.

Database & Application

With planning finished, we generated user and video game data using ChatGPT and populated our database tables. We then used Java and SQL to build the command line interface and implement core functionalities including collection creation, playing games, and account management.

Data Analysis

We finished implementing remaining functionalities and tested thoroughly. We then performed data analysis using code and Excel graphs to find trends, and displayed our results in a research poster.
